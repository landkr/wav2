# Contributing

Thank you for your interest in contributing to the AI for Digital Transformation project.

This project aims to document and develop practical applications of Artificial Intelligence for digital transformation, public-sector work, training, knowledge sharing, and community use.

## How to Contribute

There are several ways to contribute to this project:

- Share a practical AI use case.
- Suggest an improvement to an existing workflow.
- Submit documentation.
- Contribute training materials.
- Share useful prompt patterns.
- Suggest evaluation methods.
- Report errors or inconsistencies.
- Share lessons learned from real-world AI adoption.

## Contribution Guidelines

Contributions should be:

- Practical and relevant to the project's objectives.
- Clearly documented.
- Reproducible where possible.
- Based on reliable information.
- Respectful of privacy and data protection.
- Responsible in their use of Artificial Intelligence.

## AI-Generated Content

AI tools may be used to assist with contributions.

However, contributors are responsible for reviewing, verifying, and improving AI-generated content before submitting it to the project.

AI-generated information should not be treated as automatically accurate.

## Privacy and Sensitive Information

Do not submit confidential, personal, proprietary, or otherwise sensitive information to this repository.

Examples include:

- Personal identification information
- Passwords or access credentials
- Confidential government information
- Internal documents that are not publicly available
- Private datasets
- API keys or authentication tokens

When demonstrating a workflow, use public, anonymized, or synthetic data whenever possible.

## Submitting a Use Case

When submitting a new AI use case, please provide:

1. The problem being addressed.
2. The intended users.
3. The proposed AI-assisted workflow.
4. The role of human verification.
5. The expected benefits.
6. Any limitations or risks.
7. Relevant references, where applicable.

## Reporting Issues

Use GitHub Issues to report:

- Errors
- Documentation problems
- Workflow problems
- Feature requests
- Improvement suggestions
- Questions about project resources

Please provide enough context for others to understand and reproduce the issue.

## Pull Requests

Before submitting a pull request:

1. Make sure your contribution is relevant to the project.
2. Check the existing documentation to avoid unnecessary duplication.
3. Review your content for accuracy.
4. Remove confidential or sensitive information.
5. Clearly describe what has been changed and why.

## Code of Conduct

Contributors are expected to communicate respectfully and constructively.

The project welcomes contributions from people with different levels of technical experience.

The goal is to build practical knowledge that helps more people use AI effectively and responsibly.
